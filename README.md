# Safari Browser for Android

Браузер с дизайном iOS Safari для Android.

## Возможности

- 🎨 Дизайн iOS Safari (адресная строка сверху)
- 🌐 WebView — все сайты работают
- 📑 Вкладки
- 🔖 Избранное
- 📚 Список для чтения
- 📊 Прогресс-бар
- 🌙 Тёмная тема

## Сборка

APK собирается автоматически через GitHub Actions.

Скачать: вкладка **Actions** → последний успешный build → **Artifacts** → **Safari-browser-apk**.

## Установка

1. Скачайте ZIP с артефактом
2. Распакуйте — внутри `app-debug.apk`
3. Откройте APK на телефоне
4. Разрешите установку из неизвестных источников
5. Установите

## Требования

- Android 5.0+ (API 21)
- 50 МБ свободного места
